Apps Script Connection

Μια προσωπική σύνδεση ανάγνωσης μεταξύ του Google λογαριασμού σου και του ιδιωτικού Personal Apps Toolbox στο ChatGPT.

Δίνει τη δυνατότητα να κατανοείς τον κώδικα, τη δομή και τη λειτουργία των Apps Script εφαρμογών σου μέσα από τη συνομιλία, με τη δική σου εξουσιοδότηση Google.

Προσωπική πρόσβαση, με δική σου συγκατάθεση

Η πρόσβαση περιορίζεται στα δεδομένα που επιτρέπει ο συνδεδεμένος λογαριασμός Google. Η εξουσιοδότηση και τα εργαλεία λειτουργούν στο ιδιωτικό Personal Apps Toolbox. Αυτή η δημόσια σελίδα περιγράφει την εφαρμογή και την πολιτική απορρήτου της.

Όρια της σύνδεσης

Παρέχονται εργαλεία ανάγνωσης. Δεν παρέχονται αλλαγή κώδικα, εκτέλεση συναρτήσεων ή δημοσίευση εφαρμογών Google.

Η αυτόματη ανακάλυψη καλύπτει standalone scripts. Γνωστά bound scripts καταχωρίζονται με Script ID ή editor link. Δεν επιστρέφονται installed triggers, script-property values, αναλυτικά Cloud Logging μηνύματα ή rendered εφαρμογές.

Τα αποτελέσματα που ζητάς επιστρέφουν στο ChatGPT για να απαντήσει στο αίτημά σου. Διάβασε την πολιτική απορρήτου για πρόσβαση, αποθήκευση και ανάκληση.
